# ADR-0008 — Páginas-base como Fonte Visual

As páginas existentes fornecidas no projeto são a referência visual
principal.

Antes de criar páginas:

1. localizar;
2. auditar;
3. analisar;
4. identificar padrões;
5. componentizar;
6. documentar;
7. reutilizar.

Não criar nova identidade visual paralela.
