# ADR-0050 — Definition of Done

Uma funcionalidade somente está concluída quando:

- código implementado;
- tipos corretos;
- rota funcionando;
- API funcionando;
- permissões funcionando;
- loading funcionando;
- empty funcionando;
- error funcionando;
- mobile funcionando;
- acessibilidade verificada;
- testes executados;
- build executado;
- sem imports quebrados;
- sem links quebrados;
- sem placeholders;
- sem TODO crítico.

Uma aplicação somente está concluída quando todas as rotas
previstas no route-map estiverem implementadas ou explicitamente
marcadas como dependência planejada.
