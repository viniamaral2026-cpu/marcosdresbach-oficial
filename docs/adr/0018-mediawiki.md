# ADR-0018 — Motor da Base de Conhecimento

Utilizar MediaWiki como motor do Acervo/Wiki institucional.

Motivos:

- páginas;
- revisões;
- histórico;
- referências;
- categorias;
- edição;
- usuários editoriais;
- estrutura enciclopédica.

Não reinventar funcionalidades que já pertencem ao MediaWiki.
