# ADR-0014 — Imports e Aliases

Utilizar aliases:

@instituto/ui
@instituto/design-system
@instituto/layouts
@instituto/editor
@instituto/cms
@instituto/api
@instituto/auth
@instituto/permissions
@instituto/shared

Evitar imports relativos profundos.

Nenhum módulo poderá acessar arquivos internos privados de outro
módulo.
