# ADR-0068 — Testing

Criar testes para:

- cadastro;
- login;
- logout;
- verificação de e-mail;
- recuperação de senha;
- usuário autenticado;
- usuário não autenticado;
- usuário sem permissão;
- administrador;
- editor;
- pesquisador;
- genealogista;
- membro;
- acesso ao /admin;
- acesso ao /membro;
- integração Firebase → API;
- Firebase UID → usuário Neon;
- RBAC;
- repositories;
- migrations;
- APIs protegidas.

Criar também testes E2E dos principais fluxos.
