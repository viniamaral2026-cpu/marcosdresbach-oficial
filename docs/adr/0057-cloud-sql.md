# ADR-0057 — Cloud SQL / Firebase Data Connect

Não adicionar Cloud SQL ou Firebase Data Connect apenas porque são tecnologias disponíveis no ecossistema Google/Firebase.

Antes de utilizar:

1. identificar a necessidade;
2. documentar a necessidade;
3. verificar se Neon já resolve;
4. avaliar custo;
5. avaliar complexidade;
6. avaliar sincronização;
7. criar ou atualizar ADR;
8. somente então implementar.

Por padrão:

NEON = PostgreSQL principal.
