# ADR-0004 — Astro como Frontend Público

## Decisão

Utilizar Astro como tecnologia padrão dos ambientes públicos.

## Aplicações

Site
Acervo
Genealogia
Editora
Pesquisa
Área do membro, quando apropriado

## Motivos

- HTML-first;
- excelente desempenho;
- baixo JavaScript;
- SEO;
- componentes reutilizáveis;
- ilhas de interatividade;
- facilidade para conteúdo institucional.

## Regra

JavaScript somente quando houver necessidade real.
