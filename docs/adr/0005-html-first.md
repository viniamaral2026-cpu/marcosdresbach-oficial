# ADR-0005 — HTML First

As páginas públicas devem priorizar HTML semântico e CSS.

Não transformar páginas simples em aplicações SPA.

Utilizar JavaScript somente para:

- interação;
- busca dinâmica;
- filtros;
- gráficos;
- mapas;
- genealogia;
- editor;
- funcionalidades que realmente necessitem de estado.
