# Segurança

- HTTPS obrigatório
- secrets fora do Git
- password hashing forte
- sessão segura
- MFA para staff
- RBAC
- rate limiting
- CSRF quando aplicável
- CORS restritivo
- CSP
- upload validation
- antivírus/scan de arquivos
- logs sem dados sensíveis
- backup criptografado
- princípio do menor privilégio

phpMyAdmin deve ser restrito.
MariaDB não deve aceitar conexões externas desnecessárias.
