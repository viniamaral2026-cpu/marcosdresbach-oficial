# LGPD

Categorias:
- identificação
- contato
- endereço
- dados de pedidos
- dados financeiros operacionais
- dados editoriais

Princípios:
- finalidade
- necessidade
- segurança
- transparência
- retenção
- direitos do titular

Dados sensíveis devem ser tratados somente quando necessários e com controles adicionais.
