# Modelo de Domínio

## User
Identidade, autenticação e dados básicos.

## WriterProfile
Perfil editorial ligado a `users`.

Status:
- PENDING
- UNDER_REVIEW
- ACTIVE
- SUSPENDED
- REJECTED

## Book
Obra editorial.

## BookVersion
Versão imutável/revisável do livro.

## Order
Pedido do cliente.

## Payment
Estado financeiro associado ao pedido.

## Royalty
Direito financeiro do escritor.

## PrintJob
Ordem de produção.

## Shipment
Entrega física.
