# CHECKLIST INSTITUCIONAL E JURÍDICO

Preencher exclusivamente com documentos oficiais:

- [ ] ato constitutivo;
- [ ] estatuto;
- [ ] CNPJ;
- [ ] natureza jurídica;
- [ ] endereço institucional;
- [ ] diretoria;
- [ ] ata de eleição;
- [ ] mandato;
- [ ] certidões pertinentes;
- [ ] finalidade estatutária;
- [ ] CNAEs, quando aplicável;
- [ ] conta bancária institucional;
- [ ] política de governança;
- [ ] política de proteção de dados;
- [ ] política de direitos autorais;
- [ ] documentação contábil;
- [ ] regularidade fiscal, quando exigível.

## Atenção

Não utilizar “Fundação” como natureza jurídica se a entidade estiver juridicamente constituída sob outra forma. O nome institucional e a natureza jurídica devem ser conferidos na documentação oficial.
