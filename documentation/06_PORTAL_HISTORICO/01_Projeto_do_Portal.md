# PROJETO DO PORTAL HISTÓRICO

## 1. Finalidade

O portal será a camada pública do projeto de preservação e pesquisa.

## 2. Módulos

- página institucional;
- acervo;
- pessoas;
- famílias;
- documentos;
- fontes;
- variantes;
- linha do tempo;
- mapas;
- imigração;
- genealogia;
- pesquisa;
- contribuições;
- metodologia;
- notícias/publicações;
- transparência;
- contato.

## 3. Modelo conceitual

**Fonte**
→ sustenta **Documento**

**Documento**
→ registra **Evento**

**Evento**
→ envolve **Pessoa(s)**

**Pessoa**
→ participa de **Família(s)**

**Pessoa/Documento**
→ pode apresentar **Variante nominal**

## 4. Controle de qualidade

Toda informação publicada deverá possuir referência interna à fonte quando disponível.

## 5. Correções

O portal deverá registrar alterações relevantes e permitir correção documentada de informações.
